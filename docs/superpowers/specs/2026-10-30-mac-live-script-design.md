# Mac 客户端脚本

继续使用现有 Power.log 编码、训练权重、动作计划和执行确认。macOS 后端使用 PyObjC 的 Quartz 读取窗口和发送鼠标事件，AppKit 判断前台应用。相比 AppleScript，Quartz 可统一处理拖动、按键状态和多显示器坐标；无需引入截图识别模型。

校准坐标以 Quartz 窗口外框的逻辑点为基准，包含标题栏。鼠标事件使用同一坐标空间，Retina 不乘像素倍率。只操作前台应用最前面的匹配窗口；窗口移动、大小变化或日志版本过期时停止。保留 F8、Ctrl+C、STOP 文件，并支持鼠标移到窗口左上角紧急停止。

提供安装、建议模式启动、明确指定执行、坐标校准、停止及检查的 `.command` 入口。安装创建本地配置，不改系统权限或炉石日志设置。检查命令只读显示权限、窗口和日志状态。默认日志目录为 `/Applications/Hearthstone/Logs`，允许修改路径。

验收覆盖共享模型链路、逻辑坐标、前台检查、拖动中失焦释放按钮、停止控制、安装脚本和解压包回放。真实客户端验收需要本机炉石与人工校准；没有实测时明确记录。
